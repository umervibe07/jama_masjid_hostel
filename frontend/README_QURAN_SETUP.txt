IMPORTANT — large PDFs:
GitHub blocks normal Git files over 100 MiB. The supplied translation PDF is over 100 MiB, so Git LFS is required.

Before the first push after copying these files:
  git lfs install
  git add .
  git commit -m "Add Quran-e-Kareem section"
  git push origin main

In Vercel:
Project Settings -> Git -> enable Git LFS.
After enabling Git LFS, redeploy the latest commit.
