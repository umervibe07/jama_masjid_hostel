# Jama Masjid & Boys' Hostel

Production-ready React/FastAPI starter assembled from the supplied project files. Secrets are intentionally excluded; use `.env.example` files.

## Frontend
`cd frontend && npm install && npm start`

## Backend
`cd backend && python -m venv .venv && pip install -r requirements.txt && uvicorn server:app --reload --port 8001`

Set `REACT_APP_BACKEND_URL` to the backend base URL.
